# 开发环境搭建

## Arduino IDE 安装

### 下载安装
1. 访问 [Arduino官网](https://www.arduino.cc/en/software)
2. 下载对应操作系统的IDE版本
3. 按照安装向导完成安装

### 配置开发板
1. 连接Arduino开发板到电脑
2. 打开Arduino IDE
3. 选择正确的开发板型号和端口
4. 上传测试程序验证

## 3D建模软件安装

### Blender（免费开源）
1. 访问 [Blender官网](https://www.blender.org/)
2. 下载最新版本
3. 解压并运行

### 其他推荐软件
- SolidWorks（工业级）
- Fusion 360（云端协同）
- SketchUp（快速建模）
