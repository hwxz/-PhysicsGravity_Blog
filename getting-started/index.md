# 入门指南

欢迎来到物研引力！本章节将帮助您快速上手我们的学习资源。

## 学习路线

### 1. 基础知识准备
- 了解电子电路基础
- 学习C语言编程基础
- 熟悉3D建模概念

### 2. 选择学习路径
根据您的兴趣选择合适的学习路径：
- **单片机开发**：适合喜欢硬件编程的学习者
- **3D建模与打印**：适合喜欢创意设计的学习者
- **综合项目实践**：适合想要全面提升的学习者

## 快速开始

### 第一步：准备开发环境
- 下载并安装Arduino IDE
- 安装3D建模软件（Blender、SolidWorks等）

### 第二步：学习基础教程
从我们的入门教程开始：
- [Arduino入门基础](../microcontroller/arduino-basics.md)
- [3D建模入门](../3d-modeling/blender-basics.md)

### 第三步：实践项目
完成第一个小项目后，您就可以开始更高级的学习了！
