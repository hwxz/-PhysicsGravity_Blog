# 特征创建入门

## 学习目标

掌握 SolidWorks 的基本特征创建工具，理解特征的概念。

## 特征概述

特征是构成零件的基本元素：
- **草图特征**：基于草图创建的特征
- **应用特征**：直接应用于现有特征的特征

## 常用草图特征

### 拉伸凸台/基体

将草图沿垂直方向拉伸：

1. 绘制草图
2. 点击「拉伸凸台/基体」按钮
3. 设置拉伸深度
4. 点击确定

### 拉伸切除

从现有实体中移除材料：

1. 绘制草图
2. 点击「拉伸切除」按钮
3. 设置切除深度
4. 点击确定

### 旋转凸台/基体

将草图绕轴旋转：

1. 绘制草图
2. 绘制旋转轴
3. 点击「旋转凸台/基体」按钮
4. 设置旋转角度
5. 点击确定

### 扫描

将轮廓沿路径扫描：

1. 绘制扫描轮廓
2. 绘制扫描路径
3. 点击「扫描」按钮
4. 选择轮廓和路径
5. 点击确定

## 常用应用特征

### 圆角

给边线添加圆角：

1. 点击「圆角」按钮
2. 选择需要圆角的边线
3. 设置圆角半径
4. 点击确定

### 倒角

给边线添加倒角：

1. 点击「倒角」按钮
2. 选择需要倒角的边线
3. 设置倒角尺寸
4. 点击确定

### 抽壳

将实体内部掏空：

1. 点击「抽壳」按钮
2. 选择要移除的面
3. 设置壳体厚度
4. 点击确定

## 特征操作

### 编辑特征

1. 在特征管理器设计树中右键点击特征
2. 选择「编辑特征」
3. 修改参数
4. 点击确定

### 压缩特征

1. 右键点击特征
2. 选择「压缩」
3. 特征暂时隐藏

### 删除特征

1. 右键点击特征
2. 选择「删除」
3. 确认删除

## 技术要点

1. **特征顺序**：特征创建顺序影响后续编辑
2. **草图关联性**：保持草图与特征的关联
3. **特征管理**：合理组织特征树结构

## 实践练习

1. 创建一个简单的长方体（拉伸）
2. 在长方体上添加圆角
3. 创建一个圆柱体（旋转）
4. 使用抽壳工具创建空心圆柱
