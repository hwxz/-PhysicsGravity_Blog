# 草图绘制基础

## 学习目标

掌握 SolidWorks 的草图绘制工具，理解草图约束的概念。

## 草图环境

### 进入草图

1. 选择一个平面（前视、上视、右视）
2. 点击「草图绘制」按钮
3. 进入草图环境

### 草图工具栏

主要工具：
- **直线**：绘制直线
- **圆**：绘制圆
- **圆弧**：绘制圆弧
- **矩形**：绘制矩形
- **多边形**：绘制多边形
- **样条曲线**：绘制自由曲线
- **智能尺寸**：标注尺寸
- **添加几何关系**：添加约束

## 基本绘图工具

### 直线绘制

1. 点击直线工具
2. 单击起点
3. 拖动鼠标
4. 单击终点

### 圆绘制

1. 点击圆工具
2. 单击圆心
3. 拖动鼠标确定半径
4. 释放鼠标

### 矩形绘制

1. 点击矩形工具
2. 单击第一个角点
3. 拖动鼠标
4. 单击对角点

## 几何约束

### 常用约束类型

| 约束 | 功能 |
|-----|-----|
| 水平 | 使直线水平 |
| 竖直 | 使直线竖直 |
| 垂直 | 使两线垂直 |
| 平行 | 使两线平行 |
| 重合 | 使点重合 |
| 同心 | 使圆同心 |
| 相切 | 使两图元相切 |
| 相等 | 使尺寸相等 |

### 添加约束步骤

1. 选择需要约束的图元
2. 点击「添加几何关系」按钮
3. 在 PropertyManager 中选择约束类型

## 尺寸标注

### 标注直线长度

1. 点击「智能尺寸」工具
2. 选择直线
3. 拖动鼠标放置尺寸
4. 输入尺寸值

### 标注圆直径

1. 点击「智能尺寸」工具
2. 选择圆
3. 拖动鼠标放置尺寸
4. 输入直径值

## 技术要点

1. **完全定义**：确保草图完全约束
2. **约束顺序**：先添加几何约束，再标注尺寸
3. **草图质量**：避免冗余约束和过定义

## 实践练习

1. 绘制一个矩形，添加水平和竖直约束
2. 绘制两个圆，添加同心约束
3. 绘制一个三角形，标注所有边长
