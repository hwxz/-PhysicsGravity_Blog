# 工程图创建

## 学习目标

掌握 SolidWorks 工程图的创建方法，理解工程图的标准规范。

## 工程图环境

### 创建工程图

1. 点击「新建」→「工程图」
2. 选择图纸格式
3. 进入工程图环境

### 图纸格式

- **A4 横向**：常用格式
- **A4 纵向**：适合细长零件
- **自定义格式**：根据需要定制

## 视图创建

### 标准视图

1. 点击「模型视图」按钮
2. 选择要插入的零件/装配体
3. 选择视图方向（前视、上视、左视等）
4. 点击图纸放置

### 投影视图

1. 选择已有的视图
2. 点击「投影视图」按钮
3. 拖动鼠标放置投影

### 等轴测视图

1. 点击「模型视图」按钮
2. 选择「等轴测」方向
3. 点击图纸放置

### 局部视图

1. 选择要放大的区域
2. 点击「局部视图」按钮
3. 设置放大比例
4. 放置视图

## 尺寸标注

### 智能尺寸

1. 点击「智能尺寸」按钮
2. 选择要标注的边/特征
3. 拖动鼠标放置尺寸
4. 修改尺寸值

### 基准标注

1. 点击「基准标注」按钮
2. 选择基准边
3. 依次选择要标注的边
4. 尺寸自动对齐

### 形位公差

1. 点击「形位公差」按钮
2. 设置公差类型
3. 选择基准
4. 放置公差框

## 技术要点

1. **视图布局**：合理安排视图位置
2. **标注规范**：遵循国家标准
3. **图纸管理**：保持图纸整洁

2. 添加主视图、俯视图和侧视图
3. 标注尺寸和公差
