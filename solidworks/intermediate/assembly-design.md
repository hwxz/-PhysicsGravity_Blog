# 装配体设计

## 学习目标

掌握 SolidWorks 装配体设计的基本方法，理解配合关系的概念。

## 装配体环境

### 创建装配体

1. 点击「新建」→「装配体」
2. 选择模板
3. 进入装配体环境

### 插入零件

1. 点击「插入零部件」按钮
2. 选择要插入的零件
3. 点击图形区域放置零件

## 配合关系

### 常用配合类型

| 配合 | 功能 |
|-----|-----|
| 重合 | 使两个面/边/点重合 |
| 平行 | 使两个面平行 |
| 垂直 | 使两个面垂直 |
| 同轴心 | 使两个圆柱面同轴 |
| 距离 | 设置两个面之间的距离 |
| 角度 | 设置两个面之间的角度 |
| 相切 | 使两个曲面相切 |

### 添加配合步骤

1. 点击「配合」按钮
2. 选择要配合的实体
3. 在 PropertyManager 中选择配合类型
4. 设置参数
5. 点击确定

## 装配体操作

### 移动零部件

1. 点击「移动零部件」按钮
2. 选择要移动的零件
3. 拖动鼠标移动

### 旋转零部件

1. 点击「旋转零部件」按钮
2. 选择要旋转的零件
3. 拖动鼠标旋转

### 压缩零部件

1. 右键点击零件
2. 选择「压缩」
3. 零件暂时隐藏

## 装配体特征

### 装配体切除

1. 在装配体中绘制草图
2. 点击「装配体切除」按钮
3. 选择要切除的零件
4. 设置参数

### 装配体特征

1. 点击「装配体特征」按钮
2. 选择特征类型
3. 按照提示操作

## 技术要点

1. **配合顺序**：先添加主要配合，再添加次要配合
2. **配合参考**：使用稳定的参考实体
3. **装配体结构**：合理组织装配体层次

## 实践练习

1. 创建一个简单的装配体（螺栓 + 螺母）
2. 添加正确的配合关系
3. 尝试移动和旋转零部件
