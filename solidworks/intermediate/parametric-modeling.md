# 参数化建模

## 学习目标

理解参数化设计的概念，掌握方程式和配置的使用方法。

## 参数化概念

### 什么是参数化设计

参数化设计是指通过参数来驱动模型的尺寸和形状：
- 修改参数，模型自动更新
- 便于设计变更和系列化产品

### 参数类型

- **尺寸参数**：草图尺寸、特征尺寸
- **全局变量**：可在整个模型中使用的参数
- **方程式**：参数之间的数学关系

## 全局变量

### 创建全局变量

1. 点击「工具」→「方程式」
2. 在方程式对话框中点击「添加」
3. 输入变量名和值
4. 点击确定

### 使用全局变量

1. 在尺寸标注时选择「链接到数值」
2. 选择全局变量
3. 尺寸自动关联到变量

## 方程式

### 创建方程式

1. 点击「工具」→「方程式」
2. 点击「添加」
3. 输入方程式表达式
4. 点击确定

### 方程式示例

```
// 计算体积
体积 = 长度 * 宽度 * 高度

// 限制尺寸范围
直径 = IIF(长度 > 100, 20, 15)

// 关联不同特征
圆角半径 = 厚度 / 2
```

## 配置

### 创建配置

1. 在配置管理器中右键点击配置名称
2. 选择「添加配置」
3. 输入配置名称
4. 设置配置参数

### 配置使用

1. 在配置管理器中选择配置
2. 修改该配置的尺寸
3. 其他配置不受影响

## 技术要点

1. **参数命名**：使用有意义的参数名称
2. **方程式管理**：保持方程式清晰易懂
3. **配置规划**：合理规划产品系列的配置
