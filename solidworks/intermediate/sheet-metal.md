# 钣金设计

## 学习目标

掌握 SolidWorks 钣金设计的基本方法，理解钣金特征的创建。

## 钣金环境

### 进入钣金环境

1. 新建零件
2. 点击「插入」→「钣金」→「基体法兰」
3. 进入钣金环境

### 钣金参数

- **厚度**：钣金材料的厚度
- **折弯半径**：折弯处的圆角半径
- **折弯系数**：计算展开长度的系数

## 钣金特征

### 基体法兰

1. 绘制草图
2. 点击「基体法兰」按钮
3. 设置厚度和折弯半径
4. 点击确定

### 边线法兰

1. 选择要添加法兰的边线
2. 点击「边线法兰」按钮
3. 设置法兰参数
4. 点击确定

### 斜接法兰

1. 绘制法兰轮廓草图
2. 点击「斜接法兰」按钮
3. 选择要添加法兰的边线
4. 设置参数

### 绘制的折弯

1. 在钣金表面绘制折弯线
2. 点击「绘制的折弯」按钮
3. 设置折弯角度
4. 点击确定

### 切除

1. 在钣金表面绘制草图
2. 点击「拉伸切除」按钮
3. 设置切除深度
4. 点击确定

## 展开与折叠

### 展开钣金

1. 点击「展开」按钮
2. 选择要展开的折弯
3. 点击确定

### 折叠钣金

1. 点击「折叠」按钮
2. 选择要折叠的折弯
3. 点击确定

### 平板形式

1. 点击「平板形式」按钮
2. 视图切换到展开状态

## 技术要点

1. **材料选择**：考虑材料的折弯性能
2. **折弯半径**：根据材料厚度选择合适的折弯半径
3. **展开计算**：使用正确的折弯系数

1. 创建一个简单的钣金盒子
2. 添加边线法兰
3. 尝试展开和折叠操作
