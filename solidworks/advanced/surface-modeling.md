# 曲面建模

## 学习目标

掌握 SolidWorks 曲面建模的高级技巧，创建复杂曲面模型。

## 曲面概述

### 曲面类型

- **拉伸曲面**：从草图拉伸
- **旋转曲面**：绕轴旋转草图
- **扫描曲面**：沿路径扫描轮廓
- **放样曲面**：在多个轮廓之间创建曲面
- **边界曲面**：在边界曲线之间创建曲面

### 曲面操作

- **缝合曲面**：将多个曲面合并
- **剪裁曲面**：修剪曲面
- **延伸曲面**：延长曲面
- **圆角曲面**：添加圆角

## 曲面特征

### 拉伸曲面

1. 绘制草图
2. 点击「拉伸曲面」按钮
3. 设置拉伸深度
4. 点击确定

### 旋转曲面

1. 绘制草图和旋转轴
2. 点击「旋转曲面」按钮
3. 设置旋转角度
4. 点击确定

### 扫描曲面

1. 绘制扫描轮廓和路径
2. 点击「扫描曲面」按钮
3. 选择轮廓和路径
4. 设置参数

### 放样曲面

1. 绘制多个轮廓草图
2. 点击「放样曲面」按钮
3. 依次选择轮廓
4. 设置引导线（可选）
5. 点击确定

### 边界曲面

1. 绘制边界曲线
2. 点击「边界曲面」按钮
3. 选择方向 1 和方向 2 的曲线
4. 设置参数

## 曲面转实体

### 加厚曲面

1. 选择曲面
2. 点击「加厚」按钮
3. 设置厚度方向和值
4. 点击确定

### 缝合实体

1. 选择所有曲面
2. 点击「缝合曲面」按钮
3. 勾选「尝试形成实体」
4. 点击确定

## 技术要点

1. **曲线质量**：确保草图曲线光滑
2. **曲面连续性**：保持曲面之间的 G1/G2 连续
3. **模型修复**：检查和修复曲面问题

## 实践练习

1. 创建一个简单的曲面模型
2. 使用放样曲面创建复杂形状
3. 将曲面转换为实体
