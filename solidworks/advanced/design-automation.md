# 设计自动化

## 学习目标

掌握 SolidWorks 的设计自动化工具，提高设计效率。

## 设计自动化工具

### 方程式驱动设计

1. 使用全局变量定义参数
2. 创建方程式关联参数
3. 修改参数自动更新模型

### 配置管理器

1. 创建多个配置
2. 为每个配置设置不同的参数
3. 快速切换配置

### 设计表

1. 点击「插入」→「表格」→「设计表」
2. 选择要控制的参数
3. 编辑设计表
4. 自动生成配置

### API 编程

1. 打开「宏」编辑器
2. 编写 VBA 代码
3. 运行宏自动化操作

### PropertyManager 定制

1. 点击「工具」→「自定义」
2. 配置工具栏
3. 设置快捷键

## 设计表创建

### 步骤 1：启动设计表

1. 打开零件
2. 点击「插入」→「表格」→「设计表」
3. 选择「创建新设计表」
4. 点击确定

### 步骤 2：选择参数

1. 在设计表对话框中点击「添加」
2. 选择要控制的尺寸
3. 点击确定

### 步骤 3：编辑设计表

1. 在 Excel 中编辑设计表
2. 添加配置行
3. 设置各配置的参数值
4. 关闭 Excel

### 步骤 4：生成配置

1. SolidWorks 自动生成配置
2. 在配置管理器中查看配置
3. 切换不同配置

## 技术要点

1. **参数规划**：合理规划需要自动化的参数
2. **设计表管理**：保持设计表清晰易懂
3. **宏录制**：使用宏录制简化编程
